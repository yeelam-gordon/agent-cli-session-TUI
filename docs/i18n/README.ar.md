مدير جلسات في الطرفية للبحث في المحادثات المحفوظة من Copilot CLI وClaude Code وCodex CLI وQwen CLI وGemini CLI وKimi، بما فيها المحادثات التي بدأت بشكل مستقل. هذه الأدوات الست مدعومة بتعريفات مدمجة؛ ظهور السجل يعتمد على التنسيقات ومرشحات الاكتشاف، وليس ضمانًا لدعم كل CLI.

## قبل التشغيل الأول: التثبيت والخصوصية

تحتاج إلى محادثة محفوظة لدى أداة واحدة على الأقل. لاستئنافها، يجب أن يكون CLI المقابل مثبتًا، وأن تكون قد أكملت تسجيل الدخول والمصادقة المطلوبة فيه، وأن يمكن تشغيله عبر `command` المحدد، وأن يكون مجلد العمل الأصلي متاحًا. استخدم طرفية تفاعلية وإصدارًا يناسب نظام التشغيل والمعالج.

نزّل **أرشيف Core الكامل** من [Releases](https://github.com/yeelam-gordon/agent-cli-session-TUI/releases)، لا أرشيف الشيفرة المصدرية. فك ضغط جميع الملفات واحتفظ بالبرنامج و`providers/` و`prompts/` وملف `config.toml.example` المُولَّد معًا. انسخ المثال باسم `config.toml` بجوار البرنامج، من دون استبدال إعدادات موجودة. تحقق من `state_dir` و`command` وبرنامج فتح الطرفية. يحتوي `config.toml.template` في المصدر على قيم لم تُستبدل بعد؛ لا يكفي تغيير اسمه.

**تحذير قبل التشغيل:** يرسل التجميع الافتراضي `remote` عناوين الجلسات ومجلدات العمل إلى خدمة مستضافة، وقد يعمل تلقائيًا بعد اكتشاف السجل أول مرة. لا يوجد عقد API منشور للاستخدام من جهات خارجية. للتجميع دون شبكة، ابحث في النسخة عن `# [grouping]` و`# engine = "remote"`، واحذف علامة `#` من بداية السطرين وغيّر القيمة إلى `"wordmatch"`:

```toml
[grouping]
engine = "wordmatch"
```

اترك الخيارات الأخرى في صورة تعليقات. إذا كان جدول `[grouping]` مفعّلًا بالفعل، غيّر `engine` فيه ولا تضف جدولًا ثانيًا. احفظ الملف قبل تشغيل البرنامج أو قراءة السجل. يقارن `wordmatch` الكلمات؛ ليس ذكاءً اصطناعيًا محليًا ولا يتحكم في اتصالات CLI الأخرى. قد تنزّل إضافة البحث الدلالي الاختيارية نماذج عند تهيئتها؛ ابدأ بحزمة Core لتجنب تحميل هذه الإضافة.

## البحث الأول والنتيجة المتوقعة

من طرفية داخل المجلد الذي فككت ضغطه، باستخدام Windows PowerShell:

```powershell
.\agent-session-tui.exe
```

على Linux/macOS:

```sh
./agent-session-tui
```

انتظر ظهور القائمة، واضغط `/` ثم اكتب اسم مشروع أو عبارة من سجلك أنت. استخدم `↑`/`↓` لفحص التفاصيل وتأكد من الأداة والعنوان والمجلد قبل الضغط على `Enter`. عند اختيار **Resumable**، النتيجة المتوقعة هي فتح طرفية يحمّل فيها CLI المحادثة المختارة لمتابعتها. عند اختيار **Running/Waiting**، يحاول البرنامج على Windows فقط تحديد علامة تبويب مطابقة في Windows Terminal؛ عند النجاح تُحدَّد العلامة وتظهر النافذة في المقدمة. على Linux/macOS انتقل بنفسك إلى الطرفية التي تعمل. نتائج البحث والعبارات الغامضة أو المكتوبة خطأ ليست مضمونة.

برامج التشغيل الافتراضية: `wt` على Windows (والبديل `cmd`)، و`gnome-terminal` على Linux، و`osascript` مع Terminal على macOS. عدّل الإعدادات إذا لم تكن متاحة. تتوفر أهداف Core لمعالجات x64/arm64 على الأنظمة الثلاثة؛ حزم البحث الدلالي ليست متاحة لكل هدف، فتحقق من ملفات الإصدار. يلغي `Esc` البحث؛ ويغلق `q` أو `Ctrl+C` واجهة TUI دون حذف السجل أو إيقاف CLI الأخرى. إنهاء الجلسات غير مُنفّذ.
