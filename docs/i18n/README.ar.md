اعثر على محادثة في سجلات CLI المختلفة ببحث واحد. تابع المحادثة وسياقها عبر CLI الأصلي المثبّت. على Windows فقط، حاول تحديد علامة تبويب Windows Terminal العاملة المطابقة بدل فتح نافذة أخرى.

قد يرسل التجميع البعيد الافتراضي العناوين ومسارات العمل تلقائيًا؛ اختر Core + wordmatch قبل التشغيل.

<img src="../agent-session-benefits.png" alt="تصوّر: العثور على محادثة قديمة في سجلات أدوات CLI ومتابعتها" width="780">

هذا رسم توضيحي للفكرة، وليس لقطة فعلية للتطبيق. التسميات الإنجليزية والصفوف الافتراضية أمثلة وليست سجلات خاصة حقيقية.

- اعثر على موضوع أو مشروع قديم: ابحث بعبارة تتذكرها، ثم تحقق من الأداة والعنوان ومجلد العمل.
- تابع المحادثة الصحيحة: يتطلب `Enter` عند **Resumable** سجلًا محفوظًا وCLI مثبّتًا أكملت تسجيل الدخول والمصادقة فيه، ومجلد العمل الأصلي المتاح.
- اعثر على علامة تبويب Windows العاملة: يحاول البرنامج التركيز على علامة تبويب مطابقة في Windows Terminal على Windows فقط؛ ليس اتصالًا عامًا بالعمليات. على Linux/macOS انتقل يدويًا.

لا يلزم أن تكون قد بدأت المحادثة من هذه الواجهة.

## أول بحث خاص: Core + wordmatch



تحتاج إلى محادثة محفوظة لدى أداة واحدة على الأقل. لاستئنافها، يجب أن يكون CLI المقابل مثبتًا، وأن تكون قد أكملت تسجيل الدخول والمصادقة المطلوبة فيه، وأن يمكن تشغيله عبر `command` المحدد، وأن يكون مجلد العمل الأصلي متاحًا. استخدم طرفية تفاعلية وإصدارًا يناسب نظام التشغيل والمعالج.

برامج التشغيل الافتراضية: `wt` على Windows (والبديل `cmd`)، و`gnome-terminal` على Linux، و`osascript` مع Terminal على macOS. عدّل الإعدادات إذا لم تكن متاحة. تتوفر أهداف Core لمعالجات x64/arm64 على الأنظمة الثلاثة؛ حزم البحث الدلالي ليست متاحة لكل هدف، فتحقق من ملفات الإصدار. يتطلب تحديد علامات التبويب الأصلي Windows Terminal، وهو متاح على Windows فقط.



نزّل **أرشيف Core الكامل** من [Releases](https://github.com/yeelam-gordon/agent-cli-session-TUI/releases)، لا أرشيف الشيفرة المصدرية. فك ضغط جميع الملفات واحتفظ بالبرنامج و`providers/` و`prompts/` وملف `config.toml.example` المُولَّد معًا. انسخ المثال باسم `config.toml` بجوار البرنامج، من دون استبدال إعدادات موجودة. تحقق من `state_dir` و`command` وبرنامج فتح الطرفية. يحتوي `config.toml.template` في المصدر على قيم لم تُستبدل بعد؛ لا يكفي تغيير اسمه.

قارن بصمة الملف المحدد قبل التشغيل؛ التطابق ليس توقيعًا أو ضمانًا للأمان. احترم تحذيرات النظام وسياسة المؤسسة. [SHA-256](../../README.md#verify-a-release-download).



**تحذير قبل التشغيل:** يرسل التجميع الافتراضي `remote` عناوين الجلسات ومجلدات العمل إلى خدمة مستضافة، وقد يعمل تلقائيًا بعد اكتشاف السجل أول مرة. لا يوجد عقد API منشور للاستخدام من جهات خارجية. للتجميع دون شبكة، ابحث في النسخة عن `# [grouping]` و`# engine = "remote"`، واحذف علامة `#` من بداية السطرين وغيّر القيمة إلى `"wordmatch"`:



```toml
[grouping]
engine = "wordmatch"
```



اترك الخيارات الأخرى في صورة تعليقات. إذا كان جدول `[grouping]` مفعّلًا بالفعل، غيّر `engine` فيه ولا تضف جدولًا ثانيًا. احفظ الملف قبل تشغيل البرنامج أو قراءة السجل. يقارن `wordmatch` الكلمات؛ ليس ذكاءً اصطناعيًا محليًا ولا يتحكم في اتصالات CLI الأخرى. قد تنزّل إضافة البحث الدلالي الاختيارية نماذج عند تهيئتها؛ ابدأ بحزمة Core لتجنب تحميل هذه الإضافة.

## البحث الأول والنتيجة المتوقعة

ابدأ بجزء حرفي من العنوان أو اسم المشروع. توفر Core البحث بالكلمات والتطابق التقريبي؛ الترتيب حسب إعادة الصياغة الدلالية يحتاج الإضافة الاختيارية.



من طرفية داخل المجلد الذي فككت ضغطه، باستخدام Windows PowerShell:



```powershell
.\agent-session-tui.exe
```



على Linux/macOS:



```sh
./agent-session-tui
```



تُرفق ستة تعريفات للسجل ومسارات استئناف مُعدّة؛ إصدارات CLI الأصلية التي اختُبرت هنا **غير معروفة**. هذا ليس اعتمادًا للتوافق في الاستخدام الفعلي. راجع [النطاق والأدلة](../../README.md#supported-providers).

| UI | `Enter` |
|---|---|
| Resumable (محادثة قابلة للاستئناف) | استئناف عبر CLI مثبّت أكملت المصادقة فيه، مع مجلد أصلي متاح |
| Running / Waiting / Idle | على Windows فقط، محاولة التركيز على علامة تبويب Windows Terminal العاملة المطابقة؛ وإلا انتقل يدويًا |
| Archived / Stopped | استئناف عبر CLI مثبّت أكملت المصادقة فيه، مع مجلد أصلي متاح; [الحدود](../../README.md#supported-providers) |



انتظر ظهور القائمة، واضغط `/` ثم اكتب اسم مشروع أو عبارة من سجلك أنت. استخدم `↑`/`↓` لفحص التفاصيل وتأكد من الأداة والعنوان والمجلد قبل الضغط على `Enter`. عند اختيار **Resumable**، النتيجة المتوقعة هي فتح طرفية يحمّل فيها CLI المحادثة المختارة لمتابعتها.



يلغي `Esc` البحث؛ ويغلق `q` أو `Ctrl+C` واجهة TUI دون حذف السجل أو إيقاف CLI الأخرى. إنهاء الجلسات غير مُنفّذ.



- القائمة فارغة: تحقق من السجل المحفوظ وتفعيل الأداة و`state_dir`.
- تعذّر الاستئناف: تحقق من تثبيت CLI والمصادقة ومجلد العمل الأصلي.
- تعذّر التشغيل: فك الأرشيف كاملًا مع `providers/` و`prompts/` ومثال الإعدادات المُولّد، وتحقق من برنامج فتح الطرفية.

للقائمة الفارغة وأخطاء الإعدادات والتشغيل أو تحديد العلامات، وكذلك التحديث والإزالة والاستعادة، راجع [استكشاف الأخطاء بالإنجليزية](../../README.md#troubleshooting-update-and-removal). [الوثيقة الإنجليزية](../../README.md) هي المرجع التقني؛ راجع أيضًا [الإعدادات](../../README.md#configuration) و[البيانات المرسلة](../../README.md#what-remote-sends).




إذا كنت تعرف الأداة والجلسة، فسجل CLI نفسه يكفي. يفيد هذا الفهرس مع أدوات CLI أو مشاريع متعددة، عندما تتذكر الموضوع لا معرّف الجلسة.

مدير جلسات في الطرفية للبحث في المحادثات المحفوظة من Copilot CLI وClaude Code وCodex CLI وQwen CLI وGemini CLI وKimi، بما فيها المحادثات التي بدأت بشكل مستقل. هذه الأدوات الست مدعومة بتعريفات مدمجة؛ ظهور السجل يعتمد على التنسيقات ومرشحات الاكتشاف، وليس ضمانًا لدعم كل CLI.

اتبع خطوات الخصوصية قبل التشغيل؛ قد يعمل التجميع البعيد الافتراضي تلقائيًا.





### Windows Terminal

عند اختيار **Running/Waiting/Idle**، يحاول البرنامج على Windows فقط تحديد علامة تبويب مطابقة في Windows Terminal؛ عند النجاح تُحدَّد العلامة وتظهر النافذة في المقدمة. على Linux/macOS انتقل بنفسك إلى الطرفية التي تعمل. نتائج البحث والعبارات الغامضة أو المكتوبة خطأ ليست مضمونة.

**مثال افتراضي، ليس تشغيلًا مُشاهدًا ولا جلسة مرفقة:** اضغط `/` وابحث عن `build failure`، وتخيّل صفًا يعرض Claude Code · العنوان `Build failure` · المشروع `demo-project`. استخدم `↑`/`↓` لفحص الأداة والعنوان والمجلد الأصلي. إذا كانت محادثة **Resumable** المقصودة، يفتحها `Enter` عبر Claude CLI المثبّت الذي أكملت المصادقة فيه؛ يجب أن يكون المجلد متاحًا. لا يضمن المثال النتائج أو التوافق.
