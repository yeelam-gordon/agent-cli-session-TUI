<a id="install-core"></a>

## أول بحث خاص: Core + wordmatch

تحتاج إلى محادثة محفوظة وCLI مثبّت أكملت تسجيل الدخول والمصادقة فيه، ويمكن تشغيله عبر `command` المحدد، ومجلد العمل الأصلي المتاح. استخدم إصدارًا يناسب النظام والمعالج وطرفية تفاعلية. برامج فتح الطرفية الافتراضية: Windows `wt` (البديل `cmd`)، وLinux `gnome-terminal`، وmacOS `osascript` مع Terminal. إن لم تتوفر، عدّل [الإعدادات](../usage.md#configuration).

**قبل التشغيل:** في البنى التي تتضمن إعدادات الخصوصية الجديدة يكون التجميع التلقائي معطّلًا افتراضيًا، ويستخدم التجميع اليدوي `wordmatch`. قد تظل الإصدارات القديمة تستخدم التجميع البعيد تلقائيًا. اختيار `remote` صراحةً يرسل العناوين ومجلدات العمل؛ وقد يرسل ACP ملخصات عبر CLI. يوضح [PRIVACY.md](../../PRIVACY.md) مسارات التخزين وفهارس محتوى المحادثات. قد تنزّل الإضافة الدلالية نماذج؛ ولا يتحكم Core في اتصالات CLI. المثال القديم: `# engine = "remote"`؛ الجديد: `# engine = "wordmatch"`.

1. نزّل **أرشيف Core الكامل** المناسب للنظام والمعالج من [ملفات Core حسب النظام والمعالج](../usage.md#core-archive-filenames)، لا أرشيف الشيفرة المصدرية. فك الضغط كاملًا واحتفظ بالبرنامج و`providers/` و`prompts/` وملف `config.toml.example` المُولّد معًا. [قارن بصمة الملف المحدد](../usage.md#verify-a-release-download)؛ التطابق ليس توقيعًا أو ضمانًا للأمان. احترم تحذيرات النظام وسياسة المؤسسة.
2. في التثبيت الأول، انسخ المثال المُولّد إلى `config.toml` بجوار البرنامج. **لا تستبدل إعدادات موجودة ولا تكتفِ بتغيير اسم ملف المصدر `config.toml.template`.** في النسخة، ابحث عن `# [grouping]` و`# engine = "remote"`؛ احذف `#` من بداية **السطرين معًا** وغيّر القيمة:

```toml
[grouping]
engine = "wordmatch"
auto_suggest = false
```

اترك الخيارات الأخرى معلّقة. إذا كان `[grouping]` مفعّلًا بالفعل، غيّر `engine` فيه ولا تضف جدولًا مكررًا. تحقق من `state_dir` و`command`، ثم **احفظ قبل التشغيل**. يقارن `wordmatch` الكلمات المشتركة؛ ليس ذكاءً اصطناعيًا محليًا.

3. شغّل من طرفية داخل المجلد الذي فككت ضغطه:

```powershell
# Windows PowerShell
.\agent-session-tui.exe
```

```sh
# Linux/macOS
./agent-session-tui
```

## البحث الأول والنتيجة المتوقعة

4. انتظر القائمة، واضغط `/` واكتب جزءًا حرفيًا من عنوان أو مشروع في سجلك. افحص التفاصيل بـ `↑`/`↓` وتحقق من الأداة والعنوان والمجلد. اختر **Resumable** ثم اضغط `Enter`. **المتوقع:** يفتح CLI الأصلي المحادثة المختارة لمتابعتها. قد يفوّت البحث نتائج؛ إصدارات CLI الأصلية التي اختُبرت فعلًا غير معروفة. [النطاق والأدلة](../usage.md#supported-providers).

<a id="windows-terminal"></a>

عند **Running/Waiting/Idle**، يحاول البرنامج تحديد علامة مطابقة على Windows فقط؛ ليس اتصالًا عامًا بالعمليات. قد يؤدي ضغط `Enter` مرة ثانية سريعًا على المحادثة العاملة نفسها إلى **فرض استئنافها** بدل الانتقال إلى العلامة. تحقق أولًا. [مسار Windows](../usage.md#secondary-workflow-find-a-running-windows-tab).

**لا توجد نتائج؟** تحقق من السجل المحفوظ وتفعيل الأداة و`state_dir`؛ عند فشل التشغيل، تحقق من المصادقة والمجلد الأصلي وبرنامج فتح الطرفية. [استكشاف الأخطاء](../usage.md#troubleshooting-update-and-removal).

**الخروج:** يلغي `Esc` البحث؛ بعد ذلك يغلق `q` الواجهة، أو استخدم `Ctrl+C` في القائمة أو البحث دون حذف السجل أو إيقاف CLI الأخرى. إنهاء الجلسات غير مُنفّذ. [التحديث والاستعادة والإزالة](../usage.md#troubleshooting-update-and-removal).

يحفظ [دليل الاستخدام والأدلة بالإنجليزية](../usage.md) الأرقام الكاملة والنتائج السلبية والحدود. إصدار [التسجيل](../usage.md#recorded-demo) وتاريخه غير معروفين؛ ليس إثباتًا للتوافق الحالي.
