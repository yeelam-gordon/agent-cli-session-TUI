# Agent CLI Session TUI — पुरानी बातचीत खोजें और कोडिंग सत्र जारी रखें

वह डिबगिंग वाली बातचीत Claude Code, Copilot CLI या Codex में थी? मौजूदा इतिहास को एक ही दृश्य में खोजें, सही बातचीत जाँचें और संबंधित इंस्टॉल किए हुए CLI से आगे बढ़ें। बातचीत इस TUI से शुरू हुई होना ज़रूरी नहीं है।

- पुराना विषय या प्रोजेक्ट खोजें: याद आने वाला वाक्यांश खोजकर प्रदाता, शीर्षक और निर्देशिका जाँचें।
- सही बातचीत जारी रखें: **Resumable** पर `Enter` के लिए सुरक्षित इतिहास, इंस्टॉल किया हुआ CLI जिसमें आपने आवश्यक साइन-इन और पहचान सत्यापन पूरा किया है तथा उपलब्ध मूल निर्देशिका चाहिए।
- चलता हुआ Windows टैब ढूँढें: केवल Windows पर मेल खाते Windows Terminal टैब पर जाने की कोशिश होती है; यह हर प्रक्रिया से जुड़ना नहीं है। Linux/macOS पर स्वयं स्विच करें।

प्रदाता और सत्र पता हों तो उसी CLI का इतिहास पर्याप्त है। कई CLI या प्रोजेक्ट में काम करते समय, जब विषय याद हो लेकिन सत्र ID नहीं, यह सूची मदद करती है।

यह टर्मिनल सत्र प्रबंधक Copilot CLI, Claude Code, Codex CLI, Qwen CLI, Gemini CLI और Kimi की सहेजी गई बातचीत खोजता है, चाहे वे अलग-अलग शुरू की गई हों। ये छह प्रदाता शामिल हैं; रिकॉर्ड मिलना उनके प्रारूप और खोज के फ़िल्टर पर निर्भर है। हर CLI के समर्थन का दावा नहीं है।

## पहली बार चलाने से पहले: स्थापना और गोपनीयता

कम से कम एक प्रदाता में सहेजी हुई बातचीत चाहिए। उसे जारी रखने के लिए संबंधित CLI स्थापित होना चाहिए और उसमें आपके खाते का प्रमाणीकरण पूरा होना चाहिए, कॉन्फ़िगरेशन के `command` से चलना चाहिए और मूल कार्य निर्देशिका उपलब्ध होनी चाहिए। अपने ऑपरेटिंग सिस्टम और CPU के अनुकूल संस्करण को इंटरैक्टिव टर्मिनल में चलाएँ।

[Releases](https://github.com/yeelam-gordon/agent-cli-session-TUI/releases) से **पूरा Core संग्रह** डाउनलोड करें, स्रोत कोड का संग्रह नहीं। सभी फ़ाइलें निकालें और प्रोग्राम, `providers/`, `prompts/` तथा तैयार `config.toml.example` साथ रखें। उदाहरण की प्रतिलिपि प्रोग्राम के पास `config.toml` नाम से बनाएँ; पुराने कॉन्फ़िगरेशन को न बदलें। `state_dir`, `command` और टर्मिनल लॉन्चर जाँचें। स्रोत के `config.toml.template` में ऐसे प्लेसहोल्डर हैं जिनकी जगह वास्तविक मान अभी नहीं भरे गए हैं; केवल नाम बदलकर इसका उपयोग न करें।

**पहले लॉन्च से पहले चेतावनी:** डिफ़ॉल्ट `remote` समूहीकरण सत्रों के शीर्षक और कार्य निर्देशिकाएँ होस्ट की गई सेवा को भेजता है। पहली बार इतिहास मिलने के बाद यह अपने-आप चल सकता है। तीसरे पक्ष के लिए सार्वजनिक API अनुबंध नहीं है। बिना नेटवर्क समूहीकरण के लिए कॉपी में `# [grouping]` और `# engine = "remote"` खोजें। दोनों पंक्तियों के शुरू का `#` हटाएँ और मान `"wordmatch"` करें:

```toml
[grouping]
engine = "wordmatch"
```

बाकी विकल्पों को टिप्पणी के रूप में रहने दें। सक्रिय `[grouping]` तालिका पहले से हो तो उसी का `engine` बदलें; दूसरी तालिका न जोड़ें। इतिहास पढ़ने या प्रोग्राम शुरू करने से पहले फ़ाइल सहेजें। `wordmatch` शब्दों की समानता देखता है, स्थानीय AI नहीं है और प्रदाता CLI का नेटवर्क उपयोग नियंत्रित नहीं करता। वैकल्पिक अर्थ-आधारित खोज प्लगइन आरंभ होते समय मॉडल डाउनलोड कर सकता है; पहले Core चुनें ताकि यह प्लगइन लोड न हो।

## पहली खोज और अपेक्षित परिणाम

निकाले गए फ़ोल्डर के टर्मिनल में, Windows PowerShell से:

```powershell
.\agent-session-tui.exe
```

Linux/macOS पर:

```sh
./agent-session-tui
```

सूची आने दें, `/` दबाएँ और अपने इतिहास का प्रोजेक्ट नाम या वाक्यांश लिखें। `↑`/`↓` से विवरण देखें; प्रदाता, शीर्षक और निर्देशिका की पुष्टि करके `Enter` दबाएँ। **Resumable** पर अपेक्षित परिणाम है कि टर्मिनल में संबंधित CLI चुनी हुई बातचीत खोले, जिसे आप जारी रख सकें। **Running/Waiting** पर केवल Windows में मेल खाने वाला Windows Terminal टैब चुनने की कोशिश होती है। सफलता पर टैब चुना जाता है और विंडो सामने आती है। Linux/macOS पर चल रहे टर्मिनल में स्वयं जाएँ। अस्पष्ट या गलत वर्तनी वाली खोज के परिणाम की गारंटी नहीं है।

डिफ़ॉल्ट लॉन्चर: Windows में `wt` (विकल्प `cmd`), Linux में `gnome-terminal`, macOS में `osascript` और Terminal। इनके न होने पर सेटिंग बदलें। Core तीनों प्रणालियों के x64/arm64 लक्ष्य रखता है; अर्थ-आधारित खोज के पैकेज सभी लक्ष्यों पर नहीं मिलते, रिलीज़ फ़ाइलें देखें। `Esc` खोज रद्द करता है; `q` / `Ctrl+C` TUI बंद करता है, इतिहास नहीं मिटाता और अन्य CLI नहीं रोकता। सत्र समाप्त करने की सुविधा लागू नहीं है।

खाली सूची, गलत कॉन्फ़िगरेशन, लॉन्च या टैब चयन की विफलता तथा अपडेट, हटाने और बहाली के लिए [अंग्रेज़ी समस्या-निवारण](../../README.md#troubleshooting-update-and-removal) देखें। [अंग्रेज़ी दस्तावेज़](../../README.md) तकनीकी संदर्भ है; [कॉन्फ़िगरेशन](../../README.md#configuration) और [भेजी जाने वाली जानकारी](../../README.md#what-remote-sends) भी देखें।

**काल्पनिक उदाहरण; यह देखा गया वास्तविक रन या साथ मिला सत्र नहीं है:** `/` दबाकर `build failure` खोजें और Claude Code · शीर्षक `Build failure` · प्रोजेक्ट `demo-project` वाली पंक्ति की कल्पना करें। `↑`/`↓` से प्रदाता, शीर्षक और मूल निर्देशिका जाँचें। सही **Resumable** बातचीत हो तो `Enter` उसे इंस्टॉल किए और खाते का प्रमाणीकरण पूरा किए हुए Claude CLI से खोलता है; निर्देशिका उपलब्ध होनी चाहिए। परिणाम या संगतता की गारंटी नहीं।

- सूची खाली: सहेजा इतिहास, सक्रिय प्रदाता और `state_dir` जाँचें।
- बातचीत जारी नहीं होती: CLI की स्थापना, खाते का प्रमाणीकरण और मूल निर्देशिका जाँचें।
- शुरू नहीं होता: `providers/`, `prompts/` और बना हुआ कॉन्फ़िगरेशन उदाहरण सहित पूरा पैकेज निकालें; लॉन्चर जाँचें।

सहेजी गई बातचीत सूची में देखें, अपने इतिहास में खोजें और जारी रखने के लिए बातचीत चुनें। GIF में रिकॉर्डिंग के समय वाले संस्करण का अंग्रेज़ी इंटरफ़ेस है; यह वर्तमान संस्करण या हर CLI की अनुकूलता का सत्यापन नहीं है। दस्तावेज़ का अनुवाद इंटरफ़ेस या सहेजी गई बातचीत का अनुवाद नहीं करता। चलाने से पहले स्थापना में दी गई गोपनीयता सेटिंग पूरी करें। रिकॉर्डिंग का संस्करण और तारीख अज्ञात हैं। [Core इंस्टॉल करें](#install-core).
