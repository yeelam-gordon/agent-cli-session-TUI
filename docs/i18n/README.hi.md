अलग-अलग CLI के इतिहास में बातचीत एक खोज से ढूँढें। मूल स्थापित CLI से बातचीत और संदर्भ जारी रखें। केवल Windows पर, नई विंडो खोलने के बजाय मेल खाते चलते Windows Terminal टैब पर जाने की कोशिश करें।

[प्रक्रिया देखें](#first-workflow) · [Core इंस्टॉल करें](#install-core) · [प्रदाता और सीमाएँ](../../README.md#supported-providers)

डिफ़ॉल्ट दूरस्थ समूहीकरण शीर्षक और कार्य पथ अपने-आप भेज सकता है; चलाने से पहले Core + wordmatch चुनें।

<img src="../agent-session-benefits.png" alt="अवधारणा: अलग-अलग CLI के इतिहास में पुरानी बातचीत खोजकर जारी रखना" width="780">

यह अवधारणा का चित्र है, ऐप का असली स्क्रीनशॉट नहीं। अंग्रेज़ी लेबल और काल्पनिक पंक्तियाँ केवल उदाहरण हैं, वास्तविक निजी इतिहास नहीं।

- पुराना विषय या प्रोजेक्ट खोजें: याद आने वाला वाक्यांश खोजकर प्रदाता, शीर्षक और निर्देशिका जाँचें।
- सही बातचीत जारी रखें: **Resumable** पर `Enter` के लिए सहेजा गया इतिहास, इंस्टॉल किया हुआ CLI जिसमें आपने आवश्यक साइन-इन और पहचान सत्यापन पूरा किया है तथा उपलब्ध मूल निर्देशिका चाहिए।
- चलता हुआ Windows टैब ढूँढें: केवल Windows पर मेल खाते Windows Terminal टैब पर जाने की कोशिश होती है; यह हर प्रक्रिया से जुड़ना नहीं है। Linux/macOS पर स्वयं स्विच करें।

बातचीत इस TUI से शुरू हुई होना ज़रूरी नहीं है।


<a id="install-core"></a>

## पहली निजी खोज: Core + wordmatch

कम से कम एक प्रदाता में सहेजी हुई बातचीत चाहिए। उसे जारी रखने के लिए संबंधित CLI स्थापित होना चाहिए और उसमें आपके खाते का प्रमाणीकरण पूरा होना चाहिए, कॉन्फ़िगरेशन के `command` से चलना चाहिए और मूल कार्य निर्देशिका उपलब्ध होनी चाहिए। अपने ऑपरेटिंग सिस्टम और CPU के अनुकूल संस्करण को इंटरैक्टिव टर्मिनल में चलाएँ।

डिफ़ॉल्ट लॉन्चर: Windows में `wt` (विकल्प `cmd`), Linux में `gnome-terminal`, macOS में `osascript` और Terminal। इनके न होने पर सेटिंग बदलें। Core तीनों प्रणालियों के x64/arm64 लक्ष्य रखता है; अर्थ-आधारित खोज के पैकेज सभी लक्ष्यों पर नहीं मिलते, रिलीज़ फ़ाइलें देखें। मूल टैब फ़ोकस सुविधा के लिए Windows Terminal चाहिए और यह केवल Windows पर उपलब्ध है।

[Releases](https://github.com/yeelam-gordon/agent-cli-session-TUI/releases) से **पूरा Core संग्रह** डाउनलोड करें, स्रोत कोड का संग्रह नहीं। सभी फ़ाइलें निकालें और प्रोग्राम, `providers/`, `prompts/` तथा तैयार `config.toml.example` साथ रखें। उदाहरण की प्रतिलिपि प्रोग्राम के पास `config.toml` नाम से बनाएँ; पुराने कॉन्फ़िगरेशन को न बदलें। `state_dir`, `command` और टर्मिनल लॉन्चर जाँचें। स्रोत के `config.toml.template` में ऐसे प्लेसहोल्डर हैं जिनकी जगह वास्तविक मान अभी नहीं भरे गए हैं; केवल नाम बदलकर इसका उपयोग न करें।

चलाने से पहले सही फ़ाइल का डाइजेस्ट मिलाएँ; मिलान हस्ताक्षर या सुरक्षा की गारंटी नहीं है। OS चेतावनी और संगठन की नीति मानें। [SHA-256](../../README.md#verify-a-release-download).

**पहले लॉन्च से पहले चेतावनी:** डिफ़ॉल्ट `remote` समूहीकरण सत्रों के शीर्षक और कार्य निर्देशिकाएँ होस्ट की गई सेवा को भेजता है। पहली बार इतिहास मिलने के बाद यह अपने-आप चल सकता है। तीसरे पक्ष के लिए सार्वजनिक API अनुबंध नहीं है। बिना नेटवर्क समूहीकरण के लिए कॉपी में `# [grouping]` और `# engine = "remote"` खोजें। दोनों पंक्तियों के शुरू का `#` हटाएँ और मान `"wordmatch"` करें:

```toml
[grouping]
engine = "wordmatch"
```

बाकी विकल्पों को टिप्पणी के रूप में रहने दें। सक्रिय `[grouping]` तालिका पहले से हो तो उसी का `engine` बदलें; दूसरी तालिका न जोड़ें। इतिहास पढ़ने या प्रोग्राम शुरू करने से पहले फ़ाइल सहेजें। `wordmatch` शब्दों की समानता देखता है, स्थानीय AI नहीं है और प्रदाता CLI का नेटवर्क उपयोग नियंत्रित नहीं करता। वैकल्पिक अर्थ-आधारित खोज प्लगइन आरंभ होते समय मॉडल डाउनलोड कर सकता है; पहले Core चुनें ताकि यह प्लगइन लोड न हो।

## पहली खोज और अपेक्षित परिणाम

पहले शीर्षक या प्रोजेक्ट का हूबहू अंश खोजें। Core शब्द और लगभग मिलते पाठ खोजता है; अर्थ-समान वाक्यों की रैंकिंग के लिए वैकल्पिक प्लगइन चाहिए।

निकाले गए फ़ोल्डर के टर्मिनल में, Windows PowerShell से:

```powershell
.\agent-session-tui.exe
```

Linux/macOS पर:

```sh
./agent-session-tui
```

छह इतिहास परिभाषाएँ और कॉन्फ़िगर किए गए पुनः आरंभ मार्ग दिए गए हैं; यहाँ जाँचे गए मूल CLI संस्करण **अज्ञात** हैं। यह वास्तविक उपयोग में संगतता का प्रमाणन नहीं है। [दायरा और साक्ष्य](../../README.md#supported-providers) देखें।

| UI | `Enter` |
|---|---|
| Resumable (जारी रखी जा सकने वाली बातचीत) | इंस्टॉल और खाते में प्रमाणित CLI से जारी करें; मूल निर्देशिका उपलब्ध हो |
| Running / Waiting / Idle | केवल Windows पर मेल खाते चलते Windows Terminal टैब पर जाने की कोशिश; अन्य सिस्टम पर स्वयं स्विच करें |
| Archived / Stopped | इंस्टॉल और खाते में प्रमाणित CLI से जारी करें; मूल निर्देशिका उपलब्ध हो; [सीमाएँ](../../README.md#supported-providers) |



सूची आने दें, `/` दबाएँ और अपने इतिहास का प्रोजेक्ट नाम या वाक्यांश लिखें। `↑`/`↓` से विवरण देखें; प्रदाता, शीर्षक और निर्देशिका की पुष्टि करके `Enter` दबाएँ। **Resumable** पर अपेक्षित परिणाम है कि टर्मिनल में संबंधित CLI चुनी हुई बातचीत खोले, जिसे आप जारी रख सकें।

`Esc` खोज रद्द करता है; `q` / `Ctrl+C` TUI बंद करता है, इतिहास नहीं मिटाता और अन्य CLI नहीं रोकता। सत्र समाप्त करने की सुविधा लागू नहीं है।

- सूची खाली: सहेजा इतिहास, सक्रिय प्रदाता और `state_dir` जाँचें।
- बातचीत जारी नहीं होती: CLI की स्थापना, खाते का प्रमाणीकरण और मूल निर्देशिका जाँचें।
- शुरू नहीं होता: `providers/`, `prompts/` और बना हुआ कॉन्फ़िगरेशन उदाहरण सहित पूरा पैकेज निकालें; लॉन्चर जाँचें।

खाली सूची, गलत कॉन्फ़िगरेशन, लॉन्च या टैब चयन की विफलता तथा अपडेट, हटाने और बहाली के लिए [अंग्रेज़ी समस्या-निवारण](../../README.md#troubleshooting-update-and-removal) देखें। [अंग्रेज़ी दस्तावेज़](../../README.md) तकनीकी संदर्भ है; [कॉन्फ़िगरेशन](../../README.md#configuration) और [भेजी जाने वाली जानकारी](../../README.md#what-remote-sends) भी देखें।




प्रदाता और सत्र पता हों तो उसी CLI का इतिहास पर्याप्त है। कई CLI या प्रोजेक्ट में काम करते समय, जब विषय याद हो लेकिन सत्र ID नहीं, यह सूची मदद करती है।

यह टर्मिनल सत्र प्रबंधक Copilot CLI, Claude Code, Codex CLI, Qwen CLI, Gemini CLI और Kimi की सहेजी गई बातचीत खोजता है, चाहे वे अलग-अलग शुरू की गई हों। ये छह प्रदाता शामिल हैं; रिकॉर्ड मिलना उनके प्रारूप और खोज के फ़िल्टर पर निर्भर है। हर CLI के समर्थन का दावा नहीं है।

चलाने से पहले स्थापना के गोपनीयता चरण पूरे करें; डिफ़ॉल्ट दूरस्थ समूहीकरण अपने-आप चल सकता है।





### Windows Terminal

**Running/Waiting/Idle** पर केवल Windows में मेल खाने वाला Windows Terminal टैब चुनने की कोशिश होती है। सफलता पर टैब चुना जाता है और विंडो सामने आती है। Linux/macOS पर चल रहे टर्मिनल में स्वयं जाएँ। अस्पष्ट या गलत वर्तनी वाली खोज के परिणाम की गारंटी नहीं है।
