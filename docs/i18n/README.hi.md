काम याद है, लेकिन बातचीत किस CLI में थी यह नहीं? Copilot CLI, Claude Code, Codex CLI, Qwen CLI, Gemini CLI और Kimi के सहेजे इतिहास में खोजें। प्रदाता और सत्र पता हों तो उसी CLI का इतिहास पर्याप्त हो सकता है।

<img src="../agent-session-benefits.png" alt="अवधारणा: शब्द खोज केवल शीर्षक नहीं, सुरक्षित बातचीत के संदर्भ में token expires ढूँढती है और मूल CLI में सहेजी बातचीत फिर शुरू करती है। Copilot CLI, Claude Code, Codex और अन्य समर्थित हैं।" width="700">

यह अवधारणा का चित्र है, ऐप का असली स्क्रीनशॉट नहीं। अंग्रेज़ी लेबल और काल्पनिक पंक्तियाँ उदाहरण हैं।

- **पुराना काम खोजें:** कई CLI के सहेजे इतिहास में एक खोज, इस TUI के बाहर शुरू हुई बातचीत भी शामिल है।
- **मूल बातचीत जारी रखें:** इंस्टॉल किए गए मूल CLI से सहेजा संदर्भ फिर खोलें।
- **चलता Windows टैब खोजें:** मेल खाते Windows Terminal टैब पर जाने की कोशिश करें; Linux/macOS पर स्वयं स्विच करें।

<a id="install-core"></a>

## पहली निजी खोज: Core + wordmatch

सहेजा इतिहास, इंस्टॉल किया और खाते का प्रमाणीकरण पूरा किया हुआ CLI चाहिए, जो सेट किए `command` से चल सके; मूल कार्य निर्देशिका भी उपलब्ध हो। OS/CPU के अनुकूल संस्करण और इंटरैक्टिव टर्मिनल का उपयोग करें। डिफ़ॉल्ट लॉन्चर: Windows `wt` (विकल्प `cmd`), Linux `gnome-terminal`, macOS `osascript` और Terminal। न हों तो [कॉन्फ़िगरेशन](../usage.md#configuration) बदलें।

**चलाने से पहले:** नए गोपनीयता डिफ़ॉल्ट वाले बिल्ड में स्वचालित समूहीकरण बंद रहता है और मैनुअल समूहीकरण `wordmatch` इस्तेमाल करता है। पुराने रिलीज़ अब भी अपने-आप दूरस्थ समूहीकरण कर सकते हैं। स्पष्ट रूप से चुना गया `remote` शीर्षक और निर्देशिकाएँ भेजता है; ACP अपने CLI से सारांश भी भेज सकता है। [PRIVACY.md](../../PRIVACY.md) में संग्रह स्थान और बातचीत की सामग्री के खोज सूचकांक का विवरण है। अर्थ-आधारित प्लगइन मॉडल डाउनलोड कर सकता है; Core CLI के नेटवर्क को नियंत्रित नहीं करता।

1. [OS/CPU के लिए Core फ़ाइलें](../usage.md#core-archive-filenames) से OS/CPU के लिए **पूरा Core संग्रह** लें, स्रोत कोड का संग्रह नहीं। सब फ़ाइलें निकालें और प्रोग्राम, `providers/`, `prompts/` तथा तैयार `config.toml.example` साथ रखें। [सही फ़ाइल का डाइजेस्ट जाँचें](../usage.md#verify-a-release-download); मिलान हस्ताक्षर या सुरक्षा की गारंटी नहीं है। OS चेतावनियाँ और संगठन की नीति मानें।
2. पहली स्थापना में तैयार उदाहरण की प्रतिलिपि प्रोग्राम के पास `config.toml` नाम से बनाएँ। **पुराने कॉन्फ़िगरेशन पर न लिखें और स्रोत के `config.toml.template` का केवल नाम न बदलें।** प्रतिलिपि में `# [grouping]` और `# engine = "wordmatch"` (पुराने उदाहरण में `# engine = "remote"`) को अनकमेंट करें और स्वचालित समूहीकरण बंद करने सहित इस भाग को नीचे जैसा सेट करें:

```toml
[grouping]
engine = "wordmatch"
auto_suggest = false
```

बाकी विकल्पों की पंक्तियों को कमेंट के रूप में ही रहने दें। सक्रिय `[grouping]` तालिका पहले से हो तो उसी का `engine` बदलें; दूसरी तालिका न जोड़ें। `state_dir`, `command` जाँचें और **चलाने से पहले सहेजें**। `wordmatch` साझा शब्दों की तुलना करता है, स्थानीय AI नहीं है।

3. निकाले गए फ़ोल्डर के टर्मिनल से चलाएँ:

```powershell
# Windows PowerShell
.\agent-session-tui.exe
```

```sh
# Linux/macOS
./agent-session-tui
```

<a id="first-workflow"></a>

## पहली खोज और अपेक्षित परिणाम

4. सूची आने दें, `/` दबाएँ और अपने इतिहास के शीर्षक या प्रोजेक्ट का हूबहू अंश लिखें। `↑`/`↓` से प्रदाता, शीर्षक और निर्देशिका जाँचें; **Resumable** चुनकर `Enter` दबाएँ। **अपेक्षित परिणाम:** मूल CLI चुनी हुई बातचीत खोले, जिसे आप जारी रख सकें। खोज परिणाम छूट सकते हैं; वास्तव में जाँचे गए मूल CLI संस्करण अज्ञात हैं। [दायरा और साक्ष्य](../usage.md#supported-providers)।

<a id="windows-terminal"></a>

**Running/Waiting/Idle** पर केवल Windows मेल खाते टैब पर जाने की कोशिश करता है; यह हर प्रक्रिया से जुड़ना नहीं है। उसी चलते सत्र पर जल्दी दोबारा `Enter` दबाने से टैब बदलने के बजाय **बातचीत को जबरन फिर खोलने** का प्रयास हो सकता है। पहले चयन जाँचें। [Windows प्रक्रिया](../usage.md#secondary-workflow-find-a-running-windows-tab)।

**परिणाम नहीं?** सहेजा इतिहास, सक्रिय प्रदाता और `state_dir` जाँचें; लॉन्च विफल हो तो खाते का प्रमाणीकरण, मूल निर्देशिका और लॉन्चर देखें। [समस्या-निवारण](../usage.md#troubleshooting-update-and-removal)।

**बाहर निकलें:** `Esc` खोज रद्द करता है; फिर `q` TUI बंद करता है, या सूची या खोज में `Ctrl+C` दबाएँ, इतिहास नहीं मिटाता और अन्य CLI नहीं रोकता। सत्र समाप्त करने की सुविधा लागू नहीं है। [अपडेट, बहाली और हटाना](../usage.md#troubleshooting-update-and-removal)।

[अंग्रेज़ी उपयोग और साक्ष्य गाइड](../usage.md) में पूरे आँकड़े, प्रतिकूल परिणाम और सीमाएँ सुरक्षित हैं। [रिकॉर्डिंग](../usage.md#recorded-demo) का संस्करण और तारीख अज्ञात हैं; यह वर्तमान अनुकूलता का प्रमाण नहीं है।
