Концептуальная иллюстрация, не настоящий снимок приложения. Английские подписи и вымышленные строки.

- **Найдите прежнюю работу:** один поиск по нескольким сохранённым историям, включая разговоры, начатые вне этого TUI.
- **Продолжите исходный разговор:** откройте сохранённый контекст через установленную исходную CLI.
- **Найдите работающую вкладку Windows:** попробуйте выбрать подходящую вкладку Windows Terminal; в Linux/macOS переключайтесь вручную.

<a id="install-core"></a>

## Первый приватный поиск: Core + wordmatch

Нужны сохранённая история, установленная и авторизованная CLI, доступная через настроенный `command`, и доступный исходный рабочий каталог. Используйте интерактивный терминал и версию для своей ОС/CPU. Средства запуска по умолчанию: Windows `wt` (резервный `cmd`), Linux `gnome-terminal`, macOS `osascript` с Terminal. Если их нет, измените [настройки](../usage.md#configuration).

**До запуска:** в сборках с новыми настройками приватности автоматическая группировка по умолчанию выключена, ручная использует `wordmatch`. Старые выпуски могут по-прежнему автоматически группировать удалённо. Явный выбор `remote` отправляет заголовки и каталоги; ACP может отправлять сводки через CLI. [PRIVACY.md](../../PRIVACY.md) описывает пути хранения и индексы содержимого разговоров. Семантический плагин может скачивать модели; Core не управляет сетью CLI. Старый пример: `# engine = "remote"`; новый: `# engine = "wordmatch"`.

1. Скачайте из раздела [Архивы Core для ОС и CPU](../usage.md#core-archive-filenames) **полный архив Core** для своей ОС/CPU, не архив исходного кода. Распакуйте всё и оставьте вместе программу, `providers/`, `prompts/` и сгенерированный `config.toml.example`. [Проверьте дайджест точного файла](../usage.md#verify-a-release-download); совпадение не является подписью или гарантией безопасности. Соблюдайте предупреждения ОС и правила организации.
2. При новой установке скопируйте сгенерированный пример в `config.toml` рядом с программой. **Не перезаписывайте существующие настройки и не переименовывайте исходный `config.toml.template`.** В копии уберите начальный `#` из **обеих строк**, `# [grouping]` и `# engine = "remote"`, и измените значение:

```toml
[grouping]
engine = "wordmatch"
auto_suggest = false
```

Остальные параметры оставьте закомментированными. Если активная таблица `[grouping]` уже есть, измените в ней `engine`, не создавая дубликат. Проверьте `state_dir` и `command`; **сохраните до запуска**. `wordmatch` сравнивает общие слова; это не локальный ИИ.

3. Запустите из терминала в распакованной папке:

```powershell
# Windows PowerShell
.\agent-session-tui.exe
```

```sh
# Linux/macOS
./agent-session-tui
```

<a id="first-workflow"></a>

## Первый поиск и ожидаемый результат

4. Дождитесь списка, нажмите `/` и введите буквальный фрагмент заголовка или проекта из своей истории. С помощью `↑`/`↓` проверьте провайдера, заголовок и каталог; выберите **Resumable**, затем `Enter`. **Ожидается:** исходная CLI откроет выбранный разговор для продолжения. Поиск может пропустить результаты; проверенные версии нативных CLI неизвестны. [Охват и свидетельства](../usage.md#supported-providers).

<a id="windows-terminal"></a>

Для **Running/Waiting/Idle** только Windows пытается выбрать подходящую вкладку; это не универсальное подключение к процессам. Быстрое повторное `Enter` на той же работающей сессии может **принудительно возобновить** её вместо переключения вкладки. Сначала проверьте выбор. [Сценарий Windows](../usage.md#secondary-workflow-find-a-running-windows-tab).

**Нет результатов?** Проверьте сохранённую историю, включение провайдера и `state_dir`; при ошибке запуска — авторизацию, исходный каталог и средство запуска. [Устранение неполадок](../usage.md#troubleshooting-update-and-removal).

**Выход:** `Esc` отменяет поиск; затем `q` закрывает TUI, либо нажмите `Ctrl+C` в списке или поиске без удаления истории или остановки других CLI. Завершение сессий не реализовано. [Обновление, восстановление и удаление](../usage.md#troubleshooting-update-and-removal).

[Английское руководство и свидетельства](../usage.md) сохраняют все числа, отрицательные результаты и ограничения. Версия и дата [записи](../usage.md#recorded-demo) неизвестны; она не доказывает текущую совместимость.
