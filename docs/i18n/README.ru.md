Концептуальная иллюстрация, а не настоящий снимок приложения. Английские подписи и вымышленные строки служат примерами, это не реальные личные истории.

- Найдите прежнюю тему или проект: введите знакомую фразу и проверьте провайдера, заголовок и каталог.
- Продолжите нужный разговор: `Enter` на **Resumable** требует сохранённой истории, установленной и авторизованной CLI и доступного исходного каталога.
- Найдите работающую вкладку Windows: только в Windows программа пытается переключиться на подходящую вкладку Windows Terminal; это не универсальное подключение к процессам. В Linux/macOS переключайтесь вручную.

Разговор не обязательно начинать в этом TUI.


<a id="install-core"></a>

## Первый приватный поиск: Core + wordmatch

Нужен сохранённый разговор хотя бы одного провайдера. Для продолжения его CLI должна быть установлена, авторизована и доступна через настроенный `command`; исходный рабочий каталог должен оставаться доступным. Используйте интерактивный терминал и версию для своей ОС и процессора.

По умолчанию используются Windows `wt` (резервный вариант `cmd`), Linux `gnome-terminal`, macOS `osascript` с Terminal. Если их нет, измените настройки. Core выпускается для x64/arm64 на трёх ОС; семантические пакеты доступны не для всех целей, смотрите файлы выпуска. Для нативного выбора вкладок нужен Windows Terminal; функция доступна только в Windows.

В [Releases](https://github.com/yeelam-gordon/agent-cli-session-TUI/releases) скачайте **полный архив Core**, не архив исходного кода. Распакуйте всё, оставив вместе программу, `providers/`, `prompts/` и сгенерированный `config.toml.example`. Скопируйте пример в `config.toml` рядом с программой, не перезаписывая существующие настройки. Проверьте `state_dir`, `command` и запуск терминала. Исходный `config.toml.template` содержит незаменённые параметры: просто переименовывать его нельзя.

До запуска сравните дайджест точного файла; совпадение не является подписью или гарантией безопасности. Соблюдайте предупреждения ОС и правила организации. [SHA-256](../../README.md#verify-a-release-download).

**Предупреждение до запуска:** группировка `remote` включена по умолчанию, отправляет названия сессий и рабочие каталоги внешнему сервису и может запускаться автоматически после первоначального обнаружения истории. Публичного контракта API для сторонних клиентов нет. Для группировки без сети найдите в копии строки `# [grouping]` и `# engine = "remote"`, уберите начальный `#` в обеих и измените значение на `"wordmatch"`:

```toml
[grouping]
engine = "wordmatch"
```

Остальные параметры оставьте закомментированными. Если активная таблица `[grouping]` уже есть, измените её `engine`, не создавая вторую. Сохраните файл до запуска и чтения истории. `wordmatch` сравнивает слова, а не использует локальный ИИ; настройка не управляет сетью самих CLI. Необязательный плагин семантического поиска может скачивать модели при инициализации. Начните с Core, чтобы не загружать этот плагин.

## Первый поиск и ожидаемый результат

Начните с буквального фрагмента заголовка или проекта. Core поддерживает поиск по словам и нечёткое совпадение; семантические перефразировки требуют плагина.

Из терминала в распакованной папке, в Windows PowerShell:

```powershell
.\agent-session-tui.exe
```

В Linux/macOS:

```sh
./agent-session-tui
```

Включены шесть определений истории и настроенные пути продолжения; проверенные здесь версии нативных CLI **неизвестны**. Это не сертификация совместимости в реальной работе. См. [охват и свидетельства](../../README.md#supported-providers).

| UI | `Enter` |
|---|---|
| Resumable | Продолжить через установленную и авторизованную CLI; исходный каталог доступен |
| Running / Waiting / Idle | Только в Windows попытаться переключиться на соответствующую работающую вкладку Windows Terminal; иначе переключиться вручную |
| Archived / Stopped | Продолжить через установленную и авторизованную CLI; исходный каталог доступен; [limits](../../README.md#supported-providers) |



Дождитесь списка, нажмите `/` и введите проект или фразу из собственной истории. Клавишами `↑`/`↓` проверьте сведения: провайдера, название и каталог, затем нажмите `Enter`. Для **Resumable** ожидается открытие терминала, где CLI загрузит выбранный разговор для продолжения.

`Esc` отменяет поиск; `q` / `Ctrl+C` закрывает TUI, не удаляя историю и не останавливая другие CLI. Завершение сессий через TUI не реализовано.

- Пустой список: проверьте сохранённую историю, включение провайдера и `state_dir`.
- Не удаётся продолжить: проверьте установку CLI, авторизацию и исходный каталог.
- Не запускается: распакуйте весь архив с `providers/`, `prompts/` и сгенерированным примером; проверьте средство запуска терминала.

Пустой список, ошибки конфигурации, запуска или переключения вкладок, обновление, удаление и восстановление: [устранение неполадок на английском](../../README.md#troubleshooting-update-and-removal). [Английская документация](../../README.md) — технический первоисточник; см. [настройки](../../README.md#configuration) и [передаваемые данные](../../README.md#what-remote-sends).




Если провайдер и сессия известны, достаточно истории самой CLI. Этот каталог полезен для нескольких CLI или проектов, когда помните тему, а не ID сессии.

Менеджер терминальных сессий для сохранённых разговоров Copilot CLI, Claude Code, Codex CLI, Qwen CLI, Gemini CLI и Kimi, в том числе запущенных независимо друг от друга. Встроены эти шесть провайдеров; доступность записей зависит от форматов и фильтров обнаружения. Поддержка любой CLI не обещается.

До запуска выполните шаги настройки конфиденциальности; удалённая группировка по умолчанию может запускаться автоматически.





### Windows Terminal

Для **Running/Waiting/Idle** только в Windows выполняется попытка выбрать совпадающую вкладку Windows Terminal; при успехе она выбирается, а окно выходит на передний план. В Linux/macOS переключайтесь в работающий терминал вручную. Результаты поиска, особенно с опечатками, не гарантированы.
