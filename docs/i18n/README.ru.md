Менеджер терминальных сессий для сохранённых разговоров Copilot CLI, Claude Code, Codex CLI, Qwen CLI, Gemini CLI и Kimi, в том числе запущенных независимо друг от друга. Встроены эти шесть провайдеров; доступность записей зависит от форматов и фильтров обнаружения. Поддержка любой CLI не обещается.

## До первого запуска: установка и конфиденциальность

Нужен сохранённый разговор хотя бы одного провайдера. Для продолжения его CLI должна быть установлена, авторизована и доступна через настроенный `command`; исходный рабочий каталог должен оставаться доступным. Используйте интерактивный терминал и версию для своей ОС и процессора.

В [Releases](https://github.com/yeelam-gordon/agent-cli-session-TUI/releases) скачайте **полный архив Core**, не архив исходного кода. Распакуйте всё, оставив вместе программу, `providers/`, `prompts/` и сгенерированный `config.toml.example`. Скопируйте пример в `config.toml` рядом с программой, не перезаписывая существующие настройки. Проверьте `state_dir`, `command` и запуск терминала. Исходный `config.toml.template` содержит незаменённые параметры: просто переименовывать его нельзя.

**Предупреждение до запуска:** группировка `remote` включена по умолчанию, отправляет названия сессий и рабочие каталоги внешнему сервису и может запускаться автоматически после первоначального обнаружения истории. Публичного контракта API для сторонних клиентов нет. Для группировки без сети найдите в копии строки `# [grouping]` и `# engine = "remote"`, уберите начальный `#` в обеих и измените значение на `"wordmatch"`:

```toml
[grouping]
engine = "wordmatch"
```

Остальные параметры оставьте закомментированными. Если активная таблица `[grouping]` уже есть, измените её `engine`, не создавая вторую. Сохраните файл до запуска и чтения истории. `wordmatch` сравнивает слова, а не использует локальный ИИ; настройка не управляет сетью самих CLI. Необязательный плагин семантического поиска может скачивать модели при инициализации. Начните с Core, чтобы не загружать этот плагин.

## Первый поиск и ожидаемый результат

Из терминала в распакованной папке, в Windows PowerShell:

```powershell
.\agent-session-tui.exe
```

В Linux/macOS:

```sh
./agent-session-tui
```

Дождитесь списка, нажмите `/` и введите проект или фразу из собственной истории. Клавишами `↑`/`↓` проверьте сведения: провайдера, название и каталог, затем нажмите `Enter`. Для **Resumable** ожидается открытие терминала, где CLI загрузит выбранный разговор для продолжения. Для **Running/Waiting** только в Windows выполняется попытка выбрать совпадающую вкладку Windows Terminal; при успехе она выбирается, а окно выходит на передний план. В Linux/macOS переключайтесь в работающий терминал вручную. Результаты поиска, особенно с опечатками, не гарантированы.

По умолчанию используются Windows `wt` (резервный вариант `cmd`), Linux `gnome-terminal`, macOS `osascript` с Terminal. Если их нет, измените настройки. Core выпускается для x64/arm64 на трёх ОС; семантические пакеты доступны не для всех целей, смотрите файлы выпуска. `Esc` отменяет поиск; `q` / `Ctrl+C` закрывает TUI, не удаляя историю и не останавливая другие CLI. Завершение сессий через TUI не реализовано.
